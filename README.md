## Proyectos destacados

### AgroAlerta · Minería de datos y series temporales

Soy coautor de este proyecto de aula desarrollado en equipo en el ITM durante 2026. AgroAlerta integra datos de precios, producción y comercio de FAOSTAT y tasas de cambio del Banco Mundial para estudiar seis mercados de arroz y maíz en Colombia, Ecuador y Perú, con información del periodo 2012-2024.

- **Tecnologías del proyecto:** Python, pandas, NumPy y Matplotlib.
- **Preparación y exploración:** integración de fuentes, análisis exploratorio e imputación mediante KNN.
- **Modelado piloto:** comparación de métodos de series temporales y redes neuronales mediante cortes cronológicos de validación.
- **Estado:** notebooks y piloto de modelado en evaluación; la interfaz del sistema de alertas corresponde a una siguiente fase.

Documentación disponible a solicitud.

### [TrackAmazonas Lakehouse](https://github.com/PndxDLOL/TrackAmazonas_Lakehouse)

Proyecto académico de equipo desarrollado en el ITM para la asignatura Tópicos Avanzados en Bases de Datos, durante el segundo semestre de 2026. El repositorio documenta un mini lakehouse para analizar telemetría fluvial y retrasos de llegada a partir de datos sintéticos.

- **Tecnologías del proyecto:** Python, SQL, SQLite, DuckDB y Parquet.
- **Preparación de datos:** capas Bronze, Silver y Gold; validación de tipos, deduplicación y auditoría de descartes.
- **Análisis:** modelo dimensional, seguimiento histórico mediante SCD2 y ocho consultas SQL.
- **Evidencia disponible:** documentación de arquitectura, pruebas y un ensayo académico con 500.000 muestras sintéticas.

El repositorio reúne el código, las consultas y la documentación del trabajo de equipo.
